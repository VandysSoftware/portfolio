A live reference for the site's theme and building blocks. The palette reads the actual token values from styles.css, so flip the theme (top-right) to see both sets. Where to change what: colors live in the [data-theme] blocks of styles.css; shared type and buttons in styles.css; page components in index.html's inline <style> (mirrored here).

The palette

Each chip shows the live resolved value for the current theme. Semi-transparent tokens sit over a checker so their alpha reads.

How the theme is applied, one role per job:
Headings → --heading · Body → --text · Kickers & captions → --muted · CTAs & highlights → --primary · Small accents → --secondary · Neon script (sign & closers) → --script.

Brand · primary / secondary, change these two, the accents follow

--primary
Main brand color. Feeds --accent (ghost border, FAQ +/−, focus). In light it also drives headers, button & sign.
--secondary
Secondary pop. Feeds --accent2 (quote rule, project status, sign rule).
--script
Neon script (Yellowtail), closers & the sign glow
--accent = var(--primary) and --accent2 = var(--secondary), so the component CSS keeps working while you tune just the two brand tokens.
